MeshBot installer

On-device MeshCore command bot for the Heltec WiFi LoRa 32 V4. Installs from this page over USB; no tools needed.

This browser can't flash over USB. Use Chrome, Edge or Opera on a computer. Flashing needs HTTPS (or localhost).
Steps
  1. Plug the board in with a USB data cable and press Install.
  2. Pick the board's serial port. If it isn't listed, hold BOOT, tap RST, release BOOT, and try again.
  3. After install, power the board from a charger or power bank. On first boot it opens a WiFi network called MeshBot-XXXXXX (the password is on its screen); join it and the setup page opens by itself.
  4. Open the board's address in a browser to change settings (name, location, channels, MQTT).
Heltec V4 only. Installing replaces the firmware on the board. Back it up first if it holds something you want to keep (esptool read_flash 0 0x1000000 backup.bin). Your radio region and channel settings are set afterwards from the MeshCore app.
