HelBot

A MeshCore chat bot that runs on the radio itself: ping, path, wx, sun and more, with no computer or server. For the Heltec WiFi LoRa 32 V4 only.

What do you want to do?
How?

This browser can't flash over USB. Use Chrome, Edge or Opera on a computer, or the esptool steps further down. Flashing needs this page to be opened over HTTPS.

Plug the board in with a USB data cable first.

Download firmware.bin

Then follow these steps:

  1. On a phone or computer on the same WiFi as the bot, open its address from the board's screen with /update on the end, for example http://192.168.1.50/update.
  2. Log in with user admin and your web password.
  3. Choose the firmware.bin file you just downloaded and upload it.
  4. Wait about a minute while the bot restarts, then check the version on its status page.

After flashing: connect it to your WiFi

  1. Power the board from a charger or power bank; some computers hold it in the bootloader. Press RST if it doesn't restart by itself.
  2. With no WiFi saved, it opens a network called HelBot-XXXXXX. The password is shown on the board's screen. Join it from your phone and the setup page opens by itself.
  3. Choose your WiFi network and set a web password for the bot. The board restarts, joins your WiFi and shows its address on the screen.

Set it up

  1. Open the board's address in a browser and log in with user admin and your web password.
  2. On Settings: choose the bot's name, your location and UTC offset (for sun, moon and wx), the channels it answers on, and which commands are on. Save, then restart.
  3. In the MeshCore app, connect to the board like any companion radio, set your region's radio settings, and join the channel the bot should answer on.
  4. Send ping on that channel. The bot answers pong.

MQTT observer (optional, off by default)

The bot can publish the packets it hears to a MeshCore analyzer. It stays off until you pick a broker and enter your IATA location code (a nearby airport code) on the Settings page, then restart. The community brokers are shared, volunteer-run infrastructure: use your own region's code and follow the operators' rules.

Troubleshooting

The port isn't listed, or flashing won't start Use a data cable (not charge-only) and try another USB port. Then hold BOOT, tap RST, release BOOT, and try again.
I forgot the WiFi or want to switch networks Hold the BOOT button for 10 seconds. That wipes the saved WiFi (the web password stays) and the board opens its setup network again.
I can't reach the settings page Use the address shown on the board's screen. Your computer must be on the same WiFi. If the board can't join its network for three minutes after a restart, it falls back to the setup network.
The bot doesn't answer Check that the channel is in the allow-list on the Settings page, that the command is on, and that the radio settings match your mesh. The bot rate-limits its replies on purpose.
I'd rather use esptool Files and checksums for each version are on the releases page. 
pip install esptool
# new install (erases settings)
esptool.py --chip esp32s3 --port <port> --baud 921600 write_flash 0x0 firmware-merged.bin
# update over USB (keeps settings)
esptool.py --chip esp32s3 --port <port> --baud 921600 write_flash 0xe000 firmware-update.bin
